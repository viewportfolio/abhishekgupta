How I design

From flow to interface

Every project moves through the same structure — because structure is what removes friction for the user on the other end.

Research

Understand real user behaviour before drawing a single screen.

Flows

Map the journey end to end — where users hesitate, where they drop.

Wireframe

Structure hierarchy, spacing and content before visual polish.

Prototype

Make it tappable, testable, and honest about how it will feel.

Test & Ship

Validate with users, refine, and hand off a system — not just a screen.
